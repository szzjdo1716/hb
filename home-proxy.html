1. What this is1. 家里这台电脑在干什么

You want your phone to reach the open internet through a computer you trust, in a house you trust. That computer runs a small program called Xray. The phone app talks only to that computer. The computer then opens normal sites for you.

This guide uses VLESS and REALITY on port 8443. Port 443 was closed from outside on one AT&T home line. That fact is local. Another house may differ. Do not assume 443 is blocked everywhere, and do not publish which port you chose.

Anyone who has your finished link can use that house’s internet. Their actions will appear to come from that house.

手机上网，先接到你家这台电脑，网页由这台电脑去打开。电脑放在你信得过的房子里，上面跑一个小程序，叫 Xray。手机上的 App 只跟这台电脑说话。

这里用 VLESS 和 REALITY，端口按 8443 来写。有一条 AT&T 家用线路，从外面进不了 443。那是那一家的事，换一户未必如此。别把 443 当成到处都不通，也别把你最后用的端口公开出去。

完整链接到了谁手里，谁就能借你家的网上网。外面看起来，那些访问都是从你家出去的。

2. Rules before any command2. 下命令之前先记住

Do not put real values in a handbook, a screenshot, email, or chat.

Do not turn off FileVault to get auto-login. A stolen Mac with FileVault off is an open disk.

Do not turn on auto-login. It skips the password after a reboot.

Do not use the daily laptop as a 24 hour server if you can avoid it. A small always-on box is safer. If you only have the laptop, use the conservative path below.

Do not forward a port until the program is installed and the firewall allows only that program.

Do not send the private key to the phone. The phone gets the public key only.

Possible ways to stay up all day, from safer to worse:

  • Recommended: power plugged in, lid open, sleep set to never, disk sleep off, screen may sleep. Someone can still log in with the password after a reboot.
  • Acceptable if ventilated: lid closed only with power and an external display (clamshell). Heat must be able to leave.
  • Not recommended: a login item that only keeps the machine awake. Fine as a helper, useless if nobody is logged in.
  • Strongly not recommended: disablesleep so the closed lid never sleeps. Heat builds up. Do not put that machine in a bag or on a bed.
  • Strongly not recommended: auto-login, or turning FileVault off so auto-login works. Do not do this for convenience.

真实的地址、钥匙、链接，不要进手册，也不要进截图、邮件和聊天。

想自动登录就去关 FileVault，不行。FileVault 关了，电脑被拿走等于硬盘敞开。

自动登录也别开。重启之后还是要输密码。

天天带出门的笔记本，能不用来 24 小时开机就不用。一台专门开着的小机器更合适。手里只有这台笔记本，就按下面最保守的办法。

程序还没装好、防火墙还没限定只放行它，路由器上先别做转发。

私钥留在家里这台电脑上。手机只收公钥。

想让它整天开着，从稳妥到不该做，是这样：

  • 就这么做：插着电，盖子打开，系统不睡眠，硬盘不睡眠，屏幕可以睡。重启以后，人还能用密码登录。
  • 散热没问题的话可以合盖，但必须插电，并且接一台外接显示器。热要散得出去。
  • 少用：只靠登录项阻止睡眠。人已经登录时能搭把手，没人登录就没用。
  • 别做：用 disablesleep 让合上的盖子也不睡。机会发烫。别塞进包，也别放在床上。
  • 别做：为了省事开自动登录，或者为了自动登录关掉 FileVault。

5. Install on a Mac5. Mac 上怎么装

Apple silicon and Intel use the same commands after Homebrew is on the path.

  • Apple silicon: Homebrew lives in /opt/homebrew.
  • Intel: Homebrew lives in /usr/local. If brew already works, skip the path line.

Install Homebrew from the official Homebrew site if brew --version prints nothing. Then:

Homebrew 已经能在终端里找到之后，Apple 芯片和 Intel 用同一组命令。

  • Apple 芯片：Homebrew 在 /opt/homebrew。
  • Intel：在 /usr/local。brew 已经能用，就不用再管路径。

brew --version 什么都不打印，就先去 Homebrew 官网把它装上。然后：

brew install xray && xray version

Make new secrets only if this is a fresh start or the old link leaked. New secrets stop the old link.

只有第一次做，或者旧链接已经被人看到，才重新生成那几样秘密。新的一出来，旧链接就作废。

echo "UUID: $(uuidgen | tr 'A-Z' 'a-z')"; xray x25519; echo "ShortId: $(openssl rand -hex 8)"

Write them down offline. Newer Xray calls the public key Password. 抄在纸上，不要抄回这个网页。新版 Xray 把公钥标成 Password。

6. Write the config6. 配置写在哪个文件

Config path:

  • Apple silicon: /opt/homebrew/etc/xray/config.json
  • Intel: /usr/local/etc/xray/config.json

Put your private key only in that file. Use www.microsoft.com as the pretend site unless you already know another large site works. Change the phone SNI if you change this.

Test:

文件在这：

  • Apple 芯片：/opt/homebrew/etc/xray/config.json
  • Intel：/usr/local/etc/xray/config.json

私钥只写进这个文件。假装要去的网站用 www.microsoft.com，除非你已经试过另一个大网站能用。这里改了，手机上的 SNI 一起改。

先测配置：

xray run -test -config /opt/homebrew/etc/xray/config.json

On Intel, use the /usr/local path in that command. You want Configuration OK. Intel 把命令里的路径换成 /usr/local。要看到 Configuration OK.

7. Start and test on the Mac7. 先在 Mac 上跑通 
brew services restart xray
sudo lsof -nP -iTCP:8443 -sTCP:LISTEN

You want Xray listening on 8443. On macOS an IPv6 line with TCP *:8443 is normal.

Turn the Mac firewall on. Allow only the Xray program. Leave “block all incoming connections” off, or the door stays shut.

要看到 Xray 在听 8443。macOS 上出现一行 IPv6，写着 TCP *:8443，这是正常的。

Mac 的防火墙打开，只允许 Xray。不要勾「阻止所有传入连接」，勾了这扇门就关死了。

8. Keep the Mac available8. 别让这台 Mac 睡死

Conservative settings: 保守的电源设置： 

sudo pmset -a sleep 0 disksleep 0 displaysleep 10

Leave the lid open. Leave FileVault on. Do not enable auto-login.

After a macOS update, log in and check that Xray is listening again. Brew services start after login, so a reboot still needs a person once.

盖子开着。FileVault 开着。自动登录保持关闭。

macOS 更新完要有人登录，再看 Xray 是不是还在听。brew services 是登录之后才起来的，所以重启一次，还是得有人来一次。

9. Router9. 路由器只开这一扇门

Reserve the computer’s LAN address so it does not change. Forward TCP 8443 to that address. Do not turn on IP passthrough unless a second router sits behind the gateway. If a mesh router is in between, the forward belongs on that second router.

在路由器里把这台电脑的局域网地址固定住，免得它自己变。只把 TCP 8443 转到这个地址。光猫后面没有第二台路由，就不要开 IP 直通。中间还隔着一套 mesh，转发做在那一台上面。

10. Test from outside10. 换个网络再测一次

Use a port check on 8443, not 80 or 443. From another network: 测 8443，别去测 80 或 443。手机或另一台电脑要先离开家里的 Wi-Fi： 

nc -vz 203.0.113.10 8443

Replace the example address. Success means the door is open. It does not mean the keys are right. 把例子里的地址换成你自己的。通了只说明门开了，不说明钥匙是对的。

11. Phone app11. 手机上那一行自己拼

Build the link yourself. Do not copy one from a web page. 这一行在手机上自己拼。不要从网页里复制一条现成的。 

vless://YOUR_UUID@YOUR_PUBLIC_IP:8443?encryption=none&flow=xtls-rprx-vision&security=reality&sni=www.microsoft.com&fp=chrome&pbk=YOUR_PUBLIC_KEY&sid=YOUR_SHORT_ID&type=tcp

The public key in the app must match the server’s public key, never the private key. One line, no spaces. Prefer rule mode so local sites do not all detour through the house.

App 里填的公钥，必须是电脑上的公钥，不能是私钥。一整行，中间不要空格。用规则模式，家里的网站就不必绕到这台电脑再出去。

12. If the address changes12. 家里的地址变了怎么办

Home addresses change. On the server: 家用的公网地址会变。在这台电脑上再查一次： 

curl -4 -s https://ifconfig.me; echo

Update the phone address. A dynamic name is optional. Do not put the token in the handbook. 手机里的地址改成新的。动态域名可有可无。那个令牌不要写进手册。

13. If the link leaks13. 链接被人看到了

Generate a new UUID, key pair, and short ID. Restart Xray. Update the phone. The old link must die. Do not “just delete the app.”

重新做一套 UUID、一对密钥和 Short ID。重启 Xray，再改手机。旧的那条必须失效。只把 App 删掉不算完。

14. Windows variant14. 如果是 Windows

Same job, different program install. Use the official Xray Windows build, a config file with the same fields, and a firewall rule that allows only that program on TCP 8443. Forward the port on the router to that PC’s reserved LAN address.

Strongly not recommended: turning off the Windows firewall, enabling auto-logon, or sleeping the PC while calling it a server. A desktop that stays on power, lid not relevant, screen sleep allowed, is the conservative Windows path.

要做的事一样，安装方式不同。用 Xray 官方的 Windows 版本，配置里的字段照旧，防火墙只放行这个程序的 TCP 8443。路由器把端口转到这台电脑已经固定好的局域网地址。

别这么干：关掉 Windows 防火墙，打开自动登录，或者电脑睡了还说它在当服务器。台式机插着电、屏幕可以睡，这是 Windows 上该走的做法。这里没有盖子要操心。

15. Raspberry Pi with Ubuntu variant15. 如果是装 Ubuntu 的树莓派

A Pi is a better always-on box than a daily laptop, if it is updated and not exposed beyond port 8443. Install Xray from its official release, not a random script. Copy the same config shape to /usr/local/etc/xray/config.json. Open only 8443 in ufw. Reserve the Pi’s address in the router.

Strongly not recommended: running it as root for convenience, leaving SSH open to the world on port 22, or using the default ubuntu password. SSH, if needed, stays on the home network.

树莓派比天天带走的笔记本更适合一直开着，前提是系统有在更新，外面也只能碰到 8443。Xray 用官方发布的包，不要用来路不明的脚本。配置同样放到 /usr/local/etc/xray/config.json。ufw 只开 8443。路由器里把树莓派的地址固定住。

别图省事：用 root 跑，把 SSH 的 22 端口暴露到公网，或者继续用默认的 ubuntu 密码。要 SSH，就只在家里的网络里用。
