Pi Coding Agent

编码 Agent

极简且高度可扩展的终端编码 Agent (an AI that takes steps on its own to finish a task)，适合 通过扩展、技能 (skill (a saved how-to the bot can reuse))与提示模板深度定制 专属开发工作流 (workflow (a chain of steps done in order))。 适合喜欢通过扩展、技能与提示模板定制专属开发流的极客开发者。

结论是：该工具仅用于通过扩展、技能与提示模板，深度定制极简、高扩展的专属终端编码 Agent 工作流。

发给 Bot 的提示词 (prompt (the instruction you give the AI))

复制下方整段内容发送给你的 Grok Bot (xAI's AI assistant that comes with its own computer)，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

text
帮我在你的云电脑上安装 Pi Coding Agent（https://pi.dev），以后定制开发工作流和写代码用它。需要填密钥时请提醒我自己填。

需要你自己做的事

  • 准备对应模型服务商的 API (a way for programs to talk to each other) Key。
  • 收到提示后自行将密钥写入私密配置文件。
