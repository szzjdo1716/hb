Cursor CLI

编码 Agent

Cursor 官方命令行 Agent (an AI that takes steps on its own to finish a task)，适合 在云电脑执行小范围代码修改，将 Bot 额度 (quota (how much use your plan allows))留给全局决策。

结论是：适合在云电脑执行小范围代码修改，将Bot额度留给全局决策。

发给 Bot 的提示词 (prompt (the instruction you give the AI))

复制下方整段内容发送给你的 Grok Bot (xAI's AI assistant that comes with its own computer)，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

text
帮我在你的云电脑上装好 Cursor CLI（https://cursor.com/docs/cli/installation），以后小范围代码修改用它。需要登录或授权时停下来把链接发给我由我完成。

需要你自己做的事

  • 准备 Cursor 账号或相关授权凭证。
  • 在浏览器打开 Bot 发送的授权链接完成登录。
