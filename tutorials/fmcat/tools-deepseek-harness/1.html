DeepSeek Harness

编码 Agent

DeepSeek 官方开源的 「一切皆插件」架构 Agent (an AI that takes steps on its own to finish a task)，支持桌面端与 Web UI。目前处于开发者预览阶段，适合用于 代码编写、调研分析、日常办公 与 定时任务 (scheduled task (a job that runs at set times))扩展。

结论是：它是DeepSeek官方开源的插件化Agent，适合Bot配置Key后用于代码编写、调研分析与定时任务扩展。

发给 Bot 的提示词 (prompt (the instruction you give the AI))

复制下方整段内容发送给你的 Grok Bot (xAI's AI assistant that comes with its own computer)，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

text
帮我在你的云电脑上安装配置 DeepSeek Harness（https://github.com/deepseek-ai/deepseek-harness），以后日常办公、调研、写代码和跑定时任务用它。需要配置 DeepSeek API Key 时请停下来提醒我自己填。

需要你自己做的事

  • 准备好 DeepSeek API (a way for programs to talk to each other) Key
  • 待 Bot 安装完毕后，在设置中自行填入 API Key
