你能用它做什么

网页采集

采集选区、正文、图片或表格，完整保留来源链接与上下文。

截图标注

支持框选、可见区域与长截图，发送前可自由裁剪、标注与打码。

社交分享

在 X、小红书、抖音及公众号直接选 Bot 接收，保留正文、作者、互动与附件。

材料篮

收集多篇网页、截图与本地文件，合并打包成单一任务发给 Bot。

草稿与发送预览

发送前编辑说明与附件，通过预览确认 Bot 最终收到的材料。

侧栏对话

无需离开当前网页，在侧栏直接查看 Markdown (a simple way to format text with symbols) 回复并继续追问。

更多细节

Bot 选择器支持拼音与首字母搜索，可收藏常用项并设默认 Bot。
快捷键操作⌘⇧/Ctrl+Shift+7 框选截图、8 保存网页、9 快捷命令
多语言支持内置 55 种语言和地区显示，默认跟随你的浏览器。
结构化材料包自动生成编号来源与 Markdown 正文，长文转索引与附件。

安装与使用

  1. 1下载安装包前往飞书文档，下载对应浏览器的安装包文件。
  2. 2加载扩展参考文档指引，在浏览器的扩展管理页加载插件。
  3. 3授权账户固定到工具栏并打开，授权你自己的 Grok Bot (xAI's AI assistant that comes with its own computer) 账户。
  4. 4采集与发送选择目标 Bot 发送采集的材料，在侧栏查看回复。

常见问题

这是官方出品的插件吗？

不是。这是我独立开发的第三方扩展，不是 xAI 或 Cursor 官方产品。

需要本地连接器或自建中转吗？

不需要。直接在浏览器内授权你的账户即可，无需自建中转服务。

数据保存在哪里？有埋点吗？

插件没有任何分析埋点。数据与记录存在当前浏览器，只发给你选的 Bot 服务。

支持哪些浏览器？

支持 Chrome 与 Edge 120+，以及 Firefox 桌面版 140+。

社交平台的视频都能抓到吗？

不保证。无法保证每条视频都能抓取成功，若无法获取会明确标注。

插件开源吗？源码在哪里？

代码在 GitHub (a site for storing and sharing code) 开源。自有代码使用 MIT License，第三方代码和美术资产保留各自权利。
