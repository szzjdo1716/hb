Claude Code

编码 Agent

Anthropic 官方终端编码 Agent (an AI that takes steps on its own to finish a task)，适合 代码库阅读、多文件修改与命令执行，支持后台自动更新。

结论是：Claude Code适合代码库阅读、多文件修改与命令执行，支持后台自动更新。

发给 Bot 的提示词 (prompt (the instruction you give the AI))

复制下方整段内容发送给你的 Grok Bot (xAI's AI assistant that comes with its own computer)，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

text
帮我在你的云电脑上装好 Claude Code（https://code.claude.com/docs/en/setup），以后阅读代码库和多文件修改用它。需要登录或授权时停下来把链接发给我由我完成。

需要你自己做的事

  • 准备 Claude 订阅或 Anthropic Console 账号。
  • 在浏览器打开 Bot 发送的授权链接完成认证。
