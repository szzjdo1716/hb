X API 发帖（OAuth 1.0a PIN）

通讯与发布

基于 OAuth (a safe sign-in that gives an app access without sharing your password) 1.0a PIN 授权的 X 官方接口调用方案，适合让 Bot 在 云电脑 上安全执行发帖、传图与删帖任务。

结论是：该工具仅用于让 Bot 在云电脑中发帖、传图与删帖。

发给 Bot 的提示词 (prompt (the instruction you give the AI))

复制下方整段内容发送给你的 Grok Bot (xAI's AI assistant that comes with its own computer)，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

text
帮我在你的云电脑上配置 X API 发帖（https://docs.x.com/resources/fundamentals/authentication/oauth-1-0a/pin-based-oauth），以后发帖、传图和管理推文用它。需要填密钥时请提醒我自己填，需要登录授权时把链接发给我。

需要你自己做的事

  • 在 X 开发者平台创建应用并开通读写权限。
  • 打开授权链接并在收到页面 PIN 码后发送给 Bot。
