笔记本

这是浏览器里的 Jupyter。内核是 Python（Pyodide）。不是 bash，不是 Julia，也不是你电脑上的 Python。第一次加载可能较慢。

最简单：Python 一行试试

何时用

在手机或电脑浏览器里试 Python，不用安装。

何时不用

Linux 命令、Grok Build、Grok Bot、本站的 SQL 笔记本。那些请用 Linux、 Grok、 SQL。

详情

  1. 等到页面显示 Python（第一次加载可能要一分钟）。
  2. 点输入框，输入 2+2
  3. Shift+Enter（或点 Run）。应该看到 4。
  4. 别管文件列表。不要选 JavaScript 内核。

完整 JupyterLab（文件、多内核，容易晕）

本页只链到官网演示，不内嵌 JupyterLite，也不附带 Pyodide。
